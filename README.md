# TEAM_ROCKET-CodeVariant — THE PROJECT GRAVEYARD 👻

> *"Every unfinished idea deserves another life."*

A futuristic, atmospheric SaaS developer mausoleum built with **React**, **TypeScript**, and **Vite**. Exhume buried repositories, evaluate projects with rule-based revival blueprints, harvest reusable code snippets into your private vault, and track resurrected ideas back to life.

---

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Local Development Server
```bash
npm run dev
```
Open **[http://127.0.0.1:5173/](http://127.0.0.1:5173/)** in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```

## 🎨 Themes & Design Aesthetics
The application features three fully responsive, custom-tokenized themes stored in `localStorage`:
- **Graveyard Dark** (Default): Near-black background (`#080810`), toxic neon-green accents (`#80DC48`), and spectral mist lighting.
- **Ghost Light**: Crisp off-white background with botanical green highlights and high contrast.
- **Spectral Purple**: Nocturnal violet surfaces (`#0d0718`), purple accents (`#a855f7`), and neon green runes.

Switch themes instantly using the **Theme Quick Toggle** in the top navigation bar or from the **Settings** page.

## 🚀 Key Modules & Pages

1. **Dashboard**: User greeting, hero banner with glowing ghost illustration, real-time statistics (Buried, Revived, Reboot Sprints, Reusable Snippets), **Revival Radar** priority cards, and cemetery timeline telemetry.
2. **Digital Graveyard**: Interactive cemetery grid and list views with category filters (Dev Tools, AI Tools, Web Apps, Mobile, etc.), sort by revival score or recency, and live search.
3. **Bury a Project**: Modal to record post-mortems, completed milestones, remaining blockers, abandonment causes, tech stacks, repository URLs, and takeaways.
4. **Revival Advisor**: Transparent, rule-based deterministic scoring engine (0–100) providing verdicts (`REVIVE`, `REPURPOSE`, `ARCHIVE`), circular score dials, sub-score breakdowns, and interactive prioritized checklists.
5. **Reuse Engine**: Harvest and manage reusable components, custom hooks, utilities, and project ideas with syntax-highlighted code viewer and one-click clipboard copy.
6. **Risen Projects**: Track resurrected ideas out of the graveyard with sprint milestone checklists, celebration confetti, and graduation badges.
7. **Activity & Telemetry**: Weekly rhythm bar chart and chronological audit feed.
8. **Settings**: Theme picker, profile customization, intro controls, and local data backup (export/import JSON, reset sample data, and safe purge).
